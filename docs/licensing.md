# Licenciamiento (Source-Available + Comercial)

## Objetivo
Permitir que el código sea visible públicamente, pero restringir uso comercial sin pago/licencia.

## Modelos recomendados
1. `Business Source License (BSL 1.1)`
- Código visible.
- Uso comercial restringido por términos del autor.
- Puede incluir fecha de cambio de licencia futura.

2. `PolyForm Noncommercial`
- Permite uso no comercial.
- Comercial requiere licencia paga.

## Recomendación práctica para este proyecto
- Publicar repo con licencia source-available (BSL o PolyForm).
- Ofrecer licencia comercial separada para clientes que lo usen productivamente.
- Incluir contacto comercial en README.

## Archivos sugeridos en repo
- `LICENSE` (texto legal elegido).
- `COMMERCIAL_LICENSE.md` (condiciones comerciales resumidas).
- `NOTICE` (copyright/autoría).

## Importante
- MIT/Apache/GPL no sirven si querés exigir pago por uso.
- Si hay terceros en el código, revisar compatibilidad de licencias.

## Plantilla comercial mínima
- Permite uso productivo/comercial bajo contrato.
- Define cantidad de tenants, ambientes y soporte.
- Define restricciones de redistribución.
- Define renovación, expiración y terminación.
